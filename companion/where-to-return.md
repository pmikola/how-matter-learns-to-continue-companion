# Where to return

Eight questions for revisiting *How Matter Learns to Continue*. These links lead to worked examples and the existing meaning ledger; they add no pages or definitions to the book.

Use the covered PDF or the interior PDF, as labeled. Physical page numbers count from the first PDF page; printed labels are those on the book page. Place this companion folder beside the matching v48 PDF files. If your viewer ignores named destinations, enter the displayed physical page. The HTML also offers a local PDF chooser below for other folder layouts.
